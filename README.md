# Wuwa Tappo 助手

适用于 Windows 的第三方桌宠助手。支持后台原生计数、自定义次数和速率、读取桌宠当前可用次数，以及自动领取宝箱和背包到账核验。

## 下载与启动

1. 打开 [v1.0.2 下载页](../../releases/tag/v1.0.2)，下载 `WuwaTappo-ClickHelper-Portable-1.0.2.zip`。可使用同页提供的 SHA-256 文件校验。
2. 将 ZIP 完整解压到可写目录，打开助手 EXE。首次启动按提示选择自己安装的 `WuwaTappo.exe`。需要切换到助手管理的启动方式时，先从托盘退出正在运行的桌宠。
3. 在面板选择点击模式，设置次数和速率。后台原生模式可指定本轮点击次数，也可把桌宠可用次数设为目标。填写目标速率后，实际速度以保存耗时为准。

需要 Windows 10/11 64 位、Windows PowerShell 5.1、.NET Framework 4.8、WebView2，以及单独安装的 Wuwa Tappo 桌宠。
