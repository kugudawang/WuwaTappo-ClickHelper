# Wuwa Tappo 助手

适用于 Windows 的第三方桌宠助手。支持后台原生计数、自定义次数和速率、读取桌宠当前可用次数，以及自动领取宝箱和背包到账核验。

## 下载与启动

1. 打开 [v1.0.5 下载页](../../releases/tag/v1.0.5)，下载便携 ZIP 和 SHA-256 校验文件，将 ZIP 完整解压到可写目录。
2. **默认请先启动助手**。双击助手 EXE，再点「启动桌宠并连接」。首次使用时按提示选择本机安装的 WuwaTappo.exe。连接成功后，助手才能通过 **WebView2 调试接口**读取状态和执行后台计数、自动领取等操作。
3. 普通方式启动的桌宠没有开启该接口。若已先打开普通桌宠，请在助手里点「重启桌宠并连接」，按提示从 Windows 托盘完全退出桌宠。助手会接着启动并连接。
4. 需要分别启动时，可通过「更多 → 创建桌宠连接快捷方式」生成带调试参数的入口。用这个快捷方式打开桌宠后，助手可自动连接，启动顺序不限。
5. 连接后按需选择计数模式、目标和速率。实际速率受桌宠保存耗时影响。

需要 Windows 10/11 64 位、Windows PowerShell 5.1、.NET Framework 4.8、WebView2，以及单独安装的 Wuwa Tappo 桌宠。
